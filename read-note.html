Functions & Graphs

A structured study note designed to help you understand the concept and prepare for challenging examination questions.

📖 18 Pages ⏱ 25 min read 🎯 Entrance Focus

1. Introduction

A function is a mathematical relation in which every input has exactly one output. Functions are fundamental in mathematics because they allow us to describe how one quantity depends on another.

The input is usually represented by x, while the output is represented by f(x).

f(x) = y

For example, if f(x) = 2x + 3, then when x = 4:

f(4) = 2(4) + 3 = 11

2. Key Concepts

Domain

The domain of a function is the set of all possible input values for which the function is defined.

Range

The range is the set of all possible output values produced by the function.

Types of Functions

  • One-to-one function
  • Many-to-one function
  • Onto function
  • Polynomial function
  • Rational function

3. Important Formulas

(f + g)(x) = f(x) + g(x)
(f - g)(x) = f(x) - g(x)
(fg)(x) = f(x)g(x)
(f ∘ g)(x) = f(g(x))

Function composition is especially important when solving advanced examination problems.

4. Worked Example

EXAMPLE 01

If f(x) = 3x + 2, find f(5).

f(5) = 3(5) + 2 = 15 + 2 = 17
EXAMPLE 02

If f(x) = x² − 4, find f(3).

f(3) = 3² − 4 = 9 − 4 = 5

5. Entrance Exam Tips 🎯

Important: In entrance-style questions, do not only memorize formulas. First identify the domain, required operation and the exact information given in the question.
  • Read the question carefully.
  • Identify what is given and what must be found.
  • Check restrictions on the domain.
  • Simplify before calculating.
  • Check your final answer.
